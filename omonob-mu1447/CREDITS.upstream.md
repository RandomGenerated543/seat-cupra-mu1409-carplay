# Credits and provenance

**omonob** maintains Wireless CarPlay Maps and the owned map/menu/integration/standalone-installation work in this experimental prerelease.

Special thanks to **[olli991](https://github.com/olli991)** for substantial development ideas, comparisons with original instrument behavior, test feedback, and the independently installable green-menu direction. These contributions helped shape the design; they are not just an anonymous test report.

Thanks to **[octacon84](https://github.com/octacon84)** for the MU1447/SEAT contribution and already-adjusted menu/layout materials. The existing brand-specific behavior and provenance are retained.

The earlier community V2.1 package provides the public map/runtime/profile reference. The delivered V7.5 R26 package provides the accepted wireless integration reference. Unaccepted R27 position experiments are not promoted by this package.

Volkswagen / Škoda / SEAT / Audi, QNX, Apple, and upstream library authors retain their own rights and notices. SDK/OEM code and opaque receiver dependencies are not relabeled as original omonob source. The GPL text is retained for the existing public project code; it does not automatically license every binary dependency in the local SD test package.

The earlier full-toolbox authors are not the authors of this new independent manager. This package does not bundle their full toolbox, remove other projects, or rewrite their genuine attribution.
