# SEAT / CUPRA MU1447 — omonob adaptation branch

**HIGHLY EXPERIMENTAL. USE AT YOUR OWN RISK. No warranty or guarantee of compatibility, uninterrupted operation or recovery.**

This is the separate **`omonob-mu1447`** implementation branch for **P4709 / MU1447 / 790 cockpit**.

Start at **[omonob-mu1447/README.md](omonob-mu1447/README.md)** for the code, eight exact SD ZIPs, installation/prerequisite order, restore instructions, tested Wi-Fi workaround, validation and open issues.

The previous Harman-based **MU1409** implementation remains on [`main`](https://github.com/RandomGenerated543/seat-cupra-mu1409-carplay/tree/main). Existing files outside `omonob-mu1447/` are inherited legacy files; they are not this branch's installation procedure. The older stack has not been merged into these packages.

This is an unofficial adaptation of omonob's wired/native wireless work. Upstream and third-party rights and notices are retained. Full firmware images, SDKs, private keys, phone pairing data and raw personal captures are excluded.
