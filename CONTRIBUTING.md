# Contributing

Read DISCLAIMER.md and docs/STATUS.md first. Describe exact firmware, fitted cluster,
existing modifications, source revision and reproducible observations. Separate
stored/requested/acknowledged values from independently observed display effects.
Never submit OEM firmware, extracted vendor Java, SDK files, credentials or private
captures. Keep hardware testing parked. Run scripts/audit_publication.py and
scripts/test_host.py before submitting changes.
